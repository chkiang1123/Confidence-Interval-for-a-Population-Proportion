1The big idea

We want a population proportion $p$ — for example the true proportion of magazine subscribers who will renew. We cannot ask everyone, so we take a random sample of size $n$ and count successes $x$. The sample proportion is

$$ p_s = \frac{x}{n} $$

This $p_s$ is a single number, so it is almost certainly not exactly $p$. Instead we give a range of plausible values, called a confidence interval.

PopulationA fixed but unknown proportion $p$ that we want to estimate.
→
Sample$n$ randomly chosen people. We observe $x$ successes.
→
Estimate$p_s = x/n$. It varies from sample to sample.
→
Interval$p_s \pm z \times \text{SE}$. We are $(1-\alpha)100\%$ "confident" $p$ is inside.
Why the normal approximation works. When $n$ is large, the sampling distribution of $P_s$ is approximately normal with mean $p$ and variance $\frac{p(1-p)}{n}$: $$P_s \sim N\!\left(p,\ \frac{p(1-p)}{n}\right).$$ Because $p$ is unknown, we replace it by $p_s$ when calculating the standard error.

2The formula

Sample proportion=$p_s = \dfrac{x}{n}$
Standard error=$\sqrt{\dfrac{p_s(1-p_s)}{n}}$
Confidence interval=$p_s \pm z\sqrt{\dfrac{p_s(1-p_s)}{n}}$
Width=$2z\sqrt{\dfrac{p_s(1-p_s)}{n}}$
Common $z$ values
90% confidence → $z = 1.645$
95% confidence → $z = 1.960$
99% confidence → $z = 2.575$
What controls the width?
• Higher confidence → larger $z$ → wider interval.
• Larger sample size $n$ → smaller SE → narrower interval.
• $p_s$ close to $0.5$ gives the largest SE.

3From $z$ to confidence level

The confidence level is the central area under the standard normal curve between $-z$ and $z$:

$$\frac{\beta}{100} = P(-z < Z < z) = 2P(0 < Z < z).$$

5HKDSE 2020 M1 Q4

A magazine publisher wants to estimate the proportion $p$ of its current subscribers who will continue to subscribe next year. It is given that the publisher randomly selects 841 current subscribers, and 441 of them will continue to subscribe.

(a) Find an approximate 95% confidence interval for $p$.

(b) An approximate $\beta\%$ confidence interval for $p$ is now constructed. The width of the confidence interval is 0.088. Find $\beta$ correct to the nearest integer.

Step 1 — Identify what is given.

$n = 841$, number of successes $x = 441$, so

$$p_s = \frac{441}{841} \approx 0.524376,\qquad 1-p_s = \frac{400}{841}.$$

These are "nice" numbers: $841 = 29^2$, $441 = 21^2$, $400 = 20^2$.

Step 2 — Standard error. $$\sqrt{\frac{p_s(1-p_s)}{n}} = \sqrt{\frac{\frac{441}{841}\cdot\frac{400}{841}}{841}} = \frac{\sqrt{441\cdot 400}}{841\sqrt{841}} = \frac{21\cdot 20}{841\cdot 29} = \frac{420}{24389} \approx 0.017221.$$
Step 3 — (a) 95% confidence interval.

Use $z = 1.96$:

$$\left(p_s - 1.96\sqrt{\frac{p_s(1-p_s)}{n}},\ \ p_s + 1.96\sqrt{\frac{p_s(1-p_s)}{n}}\right)$$ $$= (0.524376 - 0.033753,\ 0.524376 + 0.033753)$$

∴ Approximate 95% confidence interval ≈ (0.4906, 0.5581).

Step 4 — (b) Use the width to find $z$.

The width is twice the margin of error:

$$2z\sqrt{\frac{p_s(1-p_s)}{n}} = 0.088 \;\Rightarrow\; 2z\left(\frac{420}{24389}\right) = 0.088$$ $$z = \frac{0.044 \times 24389}{420} \approx 2.555.$$
Step 5 — (b) Convert $z$ to $\beta$.

From the standard normal table, $P(0 < Z < 2.555) \approx 0.4947$.

$$\frac{\beta}{100} = P(-2.555 < Z < 2.555) = 2(0.4947) = 0.9894$$ $$\beta \approx 98.94.$$

∴ $\beta = 99$ (correct to the nearest integer).

Check: a 99% interval uses $z = 2.575$, giving width $2(2.575)(0.017221) \approx 0.0887 \approx 0.088$. Consistent.

6Common mistakes to avoid

✗ Forgetting to divide by $n$

The standard error is $\sqrt{\dfrac{p_s(1-p_s)}{n}}$, not $\sqrt{p_s(1-p_s)}$.

✗ Using the width as the margin of error

Width $= 2z \times \text{SE}$. If the width is given, halve it before dividing by SE.

✗ One-tailed instead of two-tailed

$\beta/100 = 2P(0 < Z < z)$, not $P(Z < z)$.

✗ Rounding $p_s$ too early

Keep at least 4 significant figures (or the exact fraction) until the final answer.

Meaning of "95% confident". $p$ is fixed; the interval is what varies. If we repeated the sampling many times, about 95% of the intervals built this way would contain the true $p$. Once a particular interval is calculated, $p$ is either in it or not — the 95% describes the method, not that single interval.
