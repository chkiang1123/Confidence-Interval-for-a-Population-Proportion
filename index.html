1The Big Idea

We often want to know a population proportion \(p\), for example the proportion of all subscribers who will renew, or of all HK students who wear glasses. Asking everyone is usually impossible, so we take a random sample of size \(n\) and work out the sample proportion:

\[ p_s = \frac{\text{number of successes in the sample}}{n} \]
Population proportion \(p\)
A fixed but unknown number. It is what we want to estimate.
Sample proportion \(p_s\)
Known once we take the sample, but it changes from sample to sample. It is a random variable \(P_s\).

A single number \(p_s\) (a point estimate) is almost never exactly equal to \(p\). It is better to give a range of plausible values: a confidence interval.

2Sampling Distribution of Proportions \(P_s\)

Draw many random samples, each of size \(n\), from the same population. Each sample gives its own \(p_s\). Together these values form the sampling distribution of proportions \(P_s\).

Key result (from the curriculum): when \(n\) is sufficiently large, \[ P_s \sim N\!\left(p,\ \frac{p(1-p)}{n}\right) \quad\text{approximately},\qquad \text{Standard error} = \sqrt{\frac{p(1-p)}{n}} .\] The larger the sample size \(n\), the better the approximation (and the narrower the distribution).

3Building the Confidence Interval

Since \(P_s\) is approximately normal, standardise it:

\[ Z = \frac{P_s - p}{\sqrt{\dfrac{p(1-p)}{n}}} \sim N(0,1). \]

From the standard normal table, \(P(-1.96 < Z < 1.96) = 0.95\). Rearranging:

\[ P\!\left(P_s - 1.96\sqrt{\tfrac{p(1-p)}{n}} \;<\; p \;<\; P_s + 1.96\sqrt{\tfrac{p(1-p)}{n}}\right) = 0.95 \]
Problem: the standard error contains the unknown \(p\)!
Solution (from the curriculum): since \(p\) is unknown, we use \(p_s\) to approximate \(p\) in the standard error.

Width of the interval \[ \text{width} = 2z\sqrt{\frac{p_s(1-p_s)}{n}} \] Half of the width is called the margin of error.
Reading the width
• Higher confidence ⇒ larger \(z\) ⇒ wider interval.
• Larger \(n\) ⇒ smaller SE ⇒ narrower interval.
• To halve the width, \(n\) must be about 4 times as large.

4What does "95% confident" really mean?

\(p\) is fixed. The interval is what changes from sample to sample. If we repeated the sampling many times and built an interval each time, about 95% of those intervals would contain the true \(p\).

interval contains \(p\) interval misses \(p\) true \(p\) (newest interval at the bottom)
Common misconception: "There is a 95% probability that \(p\) lies in this interval (0.49, 0.56)." Strictly speaking, once the interval is calculated, \(p\) is either in it or not. The 95% describes the method: in the long run, 95% of such intervals capture \(p\).

(a) Find an approximate 95% confidence interval for \(p\).

(b) An approximate \(\beta\%\) confidence interval for \(p\) is now constructed. The width of the confidence interval is 0.088. Find \(\beta\) correct to the nearest integer.

Step 1: Identify the information.
\(n = 841\), number of successes = 441, so \[ p_s = \frac{441}{841} \approx 0.524376 ,\qquad 1-p_s = \frac{400}{841}. \]
Step 2: Standard error. \[ \sqrt{\frac{p_s(1-p_s)}{n}} = \sqrt{\frac{\frac{441}{841}\cdot\frac{400}{841}}{841}} = \frac{\sqrt{441\times400}}{841\sqrt{841}} = \frac{21\times 20}{841\times 29} = \frac{420}{24389}\approx 0.017221 \] 💡 Nice numbers: \(841 = 29^2\), \(441 = 21^2\), \(400 = 20^2\).

9Summary & Common Mistakes

Remember
1. \(p_s = \dfrac{x}{n}\)
2. \(\text{SE} \approx \sqrt{\dfrac{p_s(1-p_s)}{n}}\)
3. CI: \(p_s \pm z \cdot \text{SE}\)
4. 95% → 1.96, 99% → 2.575
5. Width \(= 2z\cdot\text{SE}\)
6. Valid when \(n\) is large.
Avoid these mistakes
✗Using \(\sqrt{p_s(1-p_s)}\) and forgetting to divide by \(n\).
✗Using the width as the margin of error (forgetting the factor 2).
✗Using a one-tailed area: \(\beta/100 = P(Z
✗Rounding \(p_s\) too early.
✗Saying "\(p_s\) lies in the interval with 95% probability". It is \(p\) that we estimate, and \(p_s\) is always the centre.
